**Tutoring Center Management System** — *Currently in active development.*

A web-based system designed to manage tutoring center operations, including teachers, students, classes, attendance, class sessions, and tuition management.

**Tech Stack**

`ASP.NET Core` · `EF Core` · `PostgreSQL` · `JWT` · `MediatR` · `CQRS` · `Clean Architecture` · `Vertical Slice Architecture` · `FluentValidation` · `Docker` · `React`

**Engineering Focus**

* Designing domain models and business rules
* Building RESTful APIs with ASP.NET Core
* Applying Clean Architecture and CQRS
* Implementing authentication and authorization with JWT
* Writing unit tests for application logic
* Improving maintainability and separation of concerns

> 🚧 This project is actively evolving as I continue improving its domain design, architecture, testing, and backend implementation.

### 🛒 ShopNN — Fullstack E-Commerce Platform

A full-stack e-commerce application built with **ASP.NET Core 8** and **React 19**, featuring authentication, payment integration, automated testing, and containerized deployment.

**Highlights**

* 🔐 JWT authentication with refresh-token rotation
* 💳 VNPay payment integration with HMAC-SHA512 verification
* 🧪 **88 unit tests** using xUnit, Moq, and FluentAssertions
* 🐳 Docker Compose multi-container deployment
* 🌐 Nginx reverse proxy for the production frontend
* ⚛️ React 19, Vite, Zustand, and TanStack React Query

**Tech Stack**

`ASP.NET Core 8` · `EF Core` · `SQL Server` · `React 19` · `Docker` · `Nginx` · `xUnit`
